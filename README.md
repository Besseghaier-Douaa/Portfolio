**# Portfolio blog**
A personal portfolio side that introduces who i am, my projects and my skils.
This was created as both a practice in front-end development and to put my projects in one place.

*Live Demo:* https://besseghaier-douaa.github.io/Portfolio/
*Status:* started around april 2, 2026 and finished around april 25 2026. More edits were added later on

**#Features**
-Started by planning my intro, about and the sections
-Used calm color palette with aesthetic feel
-Fully responsive layout, working on large laptops to phones
-JavaScript simple animations (without a long fade-in effects that keep you waiting while scrolling)

**#Build with**
-Html
-CSS3
-JavaScript
-Canva

**#Design Process**
-*prototype:* created the intro, the details and elemets first before arraging them in a page.
-*Inspiration:* Took inspiration from diffrent canva potfolio layout and build my own.
-*full mockup in canva:* Designed the full site before started coding so i have a clear plan on how it will look like
-*Implementation:* coded section by section, made it responsive then added animations.

**#Responsive Design**
Tried to use relative units ("%","rem") instead of "px" whenever i can. Created the main layout on pc, fixed its problems on other sizes with media queries at these breakpoints:
| Breakpoint | Target |
|------------|--------|
| `max-width: 1400px` | Large laptop |
| `max-width: 1200px` | Small laptop |
| `max-width: 1024px` | Tablet landscape |
| `max-width: 768px` | Tablet portrait |
| `max-width: 480px` | Phone |

**#Debugging layout issues**
To fix any unwanted gaps or any overflow i used temporary outline for elements with css.
